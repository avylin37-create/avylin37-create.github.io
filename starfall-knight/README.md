# STARFALL｜黑曜星刃・動作試玩 01

原創程式建模與即時動作原型。角色細節尚未達到已核可概念圖的精細程度。本測試不扣英文任務資源，也不發放正式獎勵。

打開本資料夾的 index.html，按「開始動作試玩」。WASD／方向鍵移動；拖曳畫面轉視角；滾輪縮放；J／空白鍵／點擊畫面揮劍；Shift 閃避；K 充能滿時施放星刃爆發；Esc 暫停。手機使用方向鍵與技能按鈕。開始後播放本地合成音樂，可自行關閉。無遊戲內付費 API。

包含同場景角色動作、守衛追擊與攻擊預警、傷害、技能充能、勝負及重試。老師設定與角色養成仍留在原版，尚未接回本動作測試。

支援 WebGL 的裝置呈現金屬材質與陰影。無法啟動 WebGL 時改用標示清楚的相容模式，光影簡化，速度可能下降。雲端測試瀏覽器沒有 GPU，WebGL 畫質與聲音仍需實機驗收。

Three.js 採 MIT 授權，完整授權已附在 HTML。角色、武器、場景與動作由原創程式生成，未使用購買的角色模型。

## 雙角色版本 02

新增「霜影雙刃遊俠」：銀藍輕甲、短披風、兩把青藍刀；角色預覽與出戰使用同一組立體模型。與騎士相比，移速 5.8（騎士 4.5），護盾 200（騎士 240），近戰攻速較快、範圍較短，閃避冷卻 0.75 秒（騎士 1 秒）。K「霜影交叉斬」為兩段各 55 傷害，分別判定距離；同次技能不重複結算。

首頁可選騎士／遊俠，再按「以騎士出戰」或「以遊俠出戰」。畫面上方「選擇角色」返回選單並重新開始本次試玩。選擇會記在目前瀏覽器的 starfall-motion-role；不改動原版學生的養成資料。

新增驗證：切換角色的護盾與技能、選擇記憶、兩段技能只結算兩次、切回騎士、雙武器模型、兩套模型動作頂點有限值；390×844 尺寸選角頁檢查。雲端仍只能驗證光影簡化模式，GPU 材質與音樂實機驗收仍待完成。
